# Real-Time Task Manager System ⏱️✅

## Description
The Real-Time Task Manager System is a web-based application designed to help users create, assign, track, and manage tasks in real time. The system allows teams and individuals to monitor task progress, set priorities, and receive instant updates, improving productivity and collaboration. It provides a simple and responsive interface for efficient task organization and time management.

## Features
- Create, update, and delete tasks in real time  
- Assign tasks to users or team members  
- Set task priorities and deadlines  
- Track task status (To Do, In Progress, Completed)  
- Real-time updates without page refresh  
- User-friendly and responsive dashboard  

## Tools Used
- Frontend: HTML, CSS, JavaScript  
- Backend: Python (Flask)  
- Database: MongoDB
